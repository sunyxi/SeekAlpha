# SeekAlpha

## TradingView 因子策略脚本

本仓库提供一个基于日线数据的 TradingView Pine Script (`scripts/momentum_low_volatility_strategy.pine`)，用于回测**跨资产动量 + 低波动率**的多因子组合。策略侧重于月度/季度低频再平衡，以降低滑点与交易成本，并遵循学术界常见的“12 个月动量（跳过最近 1 个月）+ 低波动率”框架。

### 策略核心思想

- **横截面动量因子**：在给定的股票（或 ETF、期货）宇宙中，计算每个标的过去 12 个月（跳过最近 21 个交易日）的收益率，寻找表现持续最强的资产。
- **低波动率因子**：使用近 63 个交易日的收益率标准差衡量风险，优先持有历史波动更低的资产。
- **多因子加权**：将动量与低波动率的分位排名按照自定义权重线性组合，得到综合得分后进行排序。
- **月度/季度再平衡**：默认每月更新一次因子数据与持仓，亦可改为季度。
- **头寸控制**：支持基于 ATR 的头寸调整（可选），通过固定每笔交易占权益的风险比例来管理波动。

### Pine Script 主要功能

| 模块 | 说明 |
| --- | --- |
| 自定义标的列表 | 通过输入框配置交易标的宇宙（TradingView 代码，逗号分隔）。 |
| 因子参数 | 可调整动量回顾窗口、跳空窗口、低波标准差窗口、因子权重、做多/做空分位数等。 |
| 信号可视化 | 绘制当前图表标的的目标权重（+1 做多 / -1 做空 / 0 空仓）。 |
| 再平衡表格 | 在图表右上角展示最新的前 5 名与后 5 名标的的因子值。 |
| 交易执行 | 对于当前图表标的，依据综合得分触发 `strategy.entry` / `strategy.close`，可直接回测。 |

### 使用步骤

1. 打开 TradingView，创建新策略脚本，将 `scripts/momentum_low_volatility_strategy.pine` 的内容粘贴进去。
2. 在图表上添加策略（建议选择日线级别）。
3. 在脚本参数中：
   - 输入自定义的交易标的宇宙（例如 `NASDAQ:AAPL,NASDAQ:MSFT,...`）。
   - 选择再平衡频率（默认每月）。
   - 设定多/空分位阈值与因子权重。
   - 决定是否启用 ATR 头寸控制及单笔风险百分比。
4. 若当前图表标的不在宇宙内，脚本会提示一次警告。
5. 运行回测并查看策略报告、权益曲线、因子表格。

### 风险与限制

- TradingView 的策略订单仍然只能作用于“图表标的”。脚本使用横截面因子来判断当前标的是否应持仓，从而模拟跨资产排名的组合表现；若要构建真正的多资产组合，需要对每个标的分别运行或将逻辑移植到专业组合回测平台。
- 月度再平衡、ATR 头寸等假设并未考虑真实世界的交易成本、税费与流动性限制，请在实盘部署前进行补充测试。
- 因子参数（窗口长度、权重等）采用学术界常见默认值，建议根据自身的资产类别与交易目的进行稳健性分析（walk-forward / Monte Carlo 等）。
- 由于 Pine Script 的历史数据限制，确保所选标的有足够的历史数据（至少 12 个月 + 缓冲）。

### 后续扩展建议

- 加入质量因子（ROE、利润率等）或价值因子（市净率、市盈率）来构建更丰富的多因子模型。
- 使用更精细的头寸模型（如波动率缩放、风险平价）来提高组合的风险调整回报。
- 将脚本与 TradingView 的 webhook 结合，实现定期提醒或自动化下单。
- 在更广泛的资产类别（如债券、商品、货币）上验证因子稳健性。

欢迎根据自身需求对脚本进行修改与扩展。
