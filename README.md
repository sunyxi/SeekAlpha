# SeekAlpha

## TradingView 因子策略脚本

本仓库提供一个基于日线数据的 TradingView Pine Script (`scripts/momentum_low_volatility_strategy.pine`)，用于回测**跨资产动量 + 低波动率**的多因子组合。策略侧重于月度/季度低频再平衡，以降低滑点与交易成本，并遵循学术界常见的“12 个月动量（跳过最近 1 个月）+ 低波动率”框架。

### 策略核心思想

- **横截面动量因子**：在给定的股票（或 ETF、期货）宇宙中，计算每个标的过去 12 个月（跳过最近 21 个交易日）的收益率，寻找表现持续最强的资产。
- **低波动率因子**：使用近 63 个交易日的收益率标准差衡量风险，优先持有历史波动更低的资产。
- **多因子加权**：将动量与低波动率的分位排名按照自定义权重线性组合，得到综合得分后进行排序。
- **月度/季度再平衡**：默认每月更新一次因子数据与持仓，亦可改为季度。
- **头寸控制**：支持基于 ATR 的头寸调整（可选），通过固定每笔交易占权益的风险比例来管理波动。

### Pine Script 主要功能

| 模块 | 说明 |
| --- | --- |
| 自定义标的列表 | 通过输入框配置交易标的宇宙（TradingView 代码，逗号分隔）。 |
| 因子参数 | 可调整动量回顾窗口、跳空窗口、低波标准差窗口、因子权重、做多/做空分位数等。 |
| 信号可视化 | 绘制当前图表标的的目标权重（+1 做多 / -1 做空 / 0 空仓）。 |
| 再平衡表格 | 在图表右上角展示最新的前 5 名与后 5 名标的的因子值。 |
| 交易执行 | 对于当前图表标的，依据综合得分触发 `strategy.entry` / `strategy.close`，可直接回测。 |

### 使用步骤

1. 打开 TradingView，进入 **Pine Editor** 并创建新策略脚本，将 `scripts/momentum_low_volatility_strategy.pine` 的全部内容粘贴进去。
2. 点击 **添加到图表 (Add to chart)**，切换到日线（或以上）周期。
3. 打开策略设置（右侧齿轮图标），在参数中：
   - 输入自定义的交易标的宇宙（例如 `NASDAQ:AAPL,NASDAQ:MSFT,...`）。
   - 选择再平衡频率（默认每月）。
   - 设定多/空分位阈值与因子权重。
   - 决定是否启用 ATR 头寸控制及单笔风险百分比。
4. 在图表底部切换到 **策略测试器 (Strategy Tester)**，选择 “绩效摘要”、“绩效报告”等视图查看回测结果。
5. 若当前图表标的不在宇宙内，脚本会在图中弹窗提示；请切换到宇宙内的标的或更新输入列表。
6. 调整参数并重新运行以验证策略在不同设定下的表现。

#### 回测小贴士

- 在策略设置的 **属性 (Properties)** 页面中，可修改初始资金、交易费用与滑点，以便模拟更接近实盘的情景。
- 回测需要至少 `Momentum lookback + Skip recent` 根历史 K 线（默认约 273 根）；如果某些标的数据不足，可切换到历史更长的标的或放宽窗口。
- 想同时观察多个标的，可在不同图表中加载同一个脚本，并在参数中指定相同的宇宙；TradingView 会分别回测每个标的的进出场。
- 如果想导出交易记录，可在策略测试器的 “绩效报告” 中点击右上角的三点菜单并选择导出。

#### 如果策略测试器显示“无数据”怎么办？

- 确认图表标的包含在“Universe tickers”输入框中；若不在列表中，脚本不会对其下单。
- 请至少加载 `动量回顾 + 跳过窗口` 长度的历史数据（默认约 273 根日K）以便完成因子计算。
- 如果标的始终无法进入设定的做多/做空分位数，可适度调低 `Top percentile`/`Bottom percentile`，或改为查看在宇宙中排名更靠前的标的。


### Pine Script 参数优化思路

TradingView 暂不具备专业量化平台的自动参数搜索能力，可参考以下方式进行“伪优化”或系统化调参：

1. **利用输入项快速试参**：将关键周期、阈值设置为 `input.*` 变量，合理限定 `min`/`max`/`step` 或提供备选列表，并借助“保存为新脚本/副本”记录不同组合。
2. **编写轻量遍历器（谨慎使用）**：使用 `for` 循环遍历少量候选值，将绩效存入数组统一比较，避免在绘图函数中直接循环导致性能问题，同时注意 Pine Script 的执行上限。
3. **借助外部工具批量回测**：导出交易列表 CSV，通过 Python、Excel 等外部脚本批量修改参数并重新回测；也可配合警报 Webhook 实现半自动迭代，但需留意速率限制。
4. **组合条件自适应切换**：使用 ATR、标准差或波动率触发不同参数集，让策略在同一脚本内随市场状态自动调整。
5. **多策略/多参数并行**：在同一脚本中运行多组参数组合，用不同的 `strategy.entry` ID 跟踪绩效，同时控制各子策略的仓位占比。

> 实务建议：先根据经验缩小参数范围，每次调整后关注夏普率、最大回撤、胜率等综合指标，并记录实验日志以降低过拟合风险。

### 风险与限制

- TradingView 的策略订单仍然只能作用于“图表标的”。脚本使用横截面因子来判断当前标的是否应持仓，从而模拟跨资产排名的组合表现；若要构建真正的多资产组合，需要对每个标的分别运行或将逻辑移植到专业组合回测平台。
- 月度再平衡、ATR 头寸等假设并未考虑真实世界的交易成本、税费与流动性限制，请在实盘部署前进行补充测试。
- 因子参数（窗口长度、权重等）采用学术界常见默认值，建议根据自身的资产类别与交易目的进行稳健性分析（walk-forward / Monte Carlo 等）。
- 由于 Pine Script 的历史数据限制，确保所选标的有足够的历史数据（至少 12 个月 + 缓冲）。

### 后续扩展建议

- 加入质量因子（ROE、利润率等）或价值因子（市净率、市盈率）来构建更丰富的多因子模型。
- 使用更精细的头寸模型（如波动率缩放、风险平价）来提高组合的风险调整回报。
- 将脚本与 TradingView 的 webhook 结合，实现定期提醒或自动化下单。
- 在更广泛的资产类别（如债券、商品、货币）上验证因子稳健性。

欢迎根据自身需求对脚本进行修改与扩展。
